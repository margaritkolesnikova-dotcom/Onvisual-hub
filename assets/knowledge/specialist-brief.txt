Сейв, создай мне профессиональный промпт для ИИ-специалиста.

Краткий бриф:

1. Специалист: [кто нужен — креативный директор, юрист, аналитик, промпт-инженер, режиссёр, маркетолог и т.д.]

2. Задача: [для чего он нужен, какую основную проблему должен помогать решать]

3. Сфера: [в каком контексте он работает — бизнес, реклама, AI-продакшн, детская анимация, юриспруденция, финансы, маркетплейсы и т.д.]

4. Результат: [что он должен выдавать — идеи, сценарии, промпты, анализ, стратегию, правки, таблицы, план действий, юридические риски и т.д.]

5. Уровень: [эксперт / senior / топ-специалист / уровень крупного бренда / уровень практикующего профессионала]

6. Стиль ответа: [кратко / подробно / структурно / критично / креативно / простым языком / без воды / с конкретикой]

7. Что обязательно учитывать: [риски, сроки, бюджет, аудиторию, реализацию, закон, оригинальность, рынок, конкурентов, технические ограничения и т.д.]

8. Чего избегать: [воды, банальностей, неподтверждённых фактов, лишней теории, копирования чужих идей, поверхностных советов]

9. Проверка: [факты / актуальность / достоверность / оригинальность / риск сходства / юридические или финансовые риски]

10. Формат промпта: [полный промпт / короткий промпт / обе версии / системный промпт для нового чата]

Минимально важно указать:
— кто специалист;
— для какой задачи он нужен;
— в какой сфере работает;
— что должен выдавать;
— что обязательно учитывать.

На основе этого брифа собери готовый промпт для копирования, чтобы ИИ в новом чате мог работать как специалист высокого уровня: грамотно, структурно, без воды, с профессиональной логикой, проверкой фактов при необходимости, учётом рисков и понятным итоговым результатом.
